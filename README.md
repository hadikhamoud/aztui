# AZTUI

## Azure Devops Terminal Utility (opentui)

### Current Features 
- view projects and repos
- view pipelines, and runs. (run details work in progress)
- clone repo in any directory via ssh or https using PAT, with live clone output in the TUI
- view PRs and act on them
- create PRs
- yank repo links
- yank build links
- view pipeline build runs and open logs for any loggable build step
- open PRs in browser
- create new repositories
- easier login flow
- early exit when token invalid



install using the install script `install.sh`

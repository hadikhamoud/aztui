# AZTUI

## Azure Devops Terminal Utility (opentui)

### Current Features 
- view projects and repos
- view pipelines, and runs. (run details work in progress)
- clone repo in any directory ssh or https using PAT
- view PRs and act on them
- create PRs
- yank repo links
- yank build links
- view pipeline build runs
- open PRs in browser
- create new repositories
- easier login flow


### Planned Features
- add work item viewer (maybe inside workspaces or as a fourth view since independent from project 
- Brush up comment addition and resolution

install using the install script `install.sh`
